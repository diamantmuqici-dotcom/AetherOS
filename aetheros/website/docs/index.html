FAQ

Is it free? Yes. Open source under MIT.

Does it support .exe / .dmg? .exe via Wine. .dmg/.pkg are macOS binaries — not run directly, Aether shows a helper prompt and suggests a Linux alternative.

How do I verify the ISO? sha256sum -c *.iso.sha256

AetherOS — private by design. Verify checksums before installing.
