Install in 3 steps

  1. Download the ISO + .sha256 from Releases, verify it.
  2. Flash with Rufus (UEFI, GPT, DD mode) or Ventoy, USB ≥ 8 GB.
  3. Boot the USB → Aether Setup → wallpaper, appearance, privacy, gaming → Enter AetherOS. No reboot needed.
Inside AetherOS

Fast, familiar, and it doesn't watch you

A desktop that feels familiar

Dock, taskbar, launcher, notifications, workspaces, snap windows — GNOME Wayland underneath, Aether's own shell extensions on top.

Gaming, built instaged

Steam + Proton-GE, Game Mode (priority boost for your running game, restored on exit), controller support via evdev. No fake universal-compatibility promises — graphics-only tuning, your inputs are never touched.

Private by default

No telemetry, no ad IDs, no behavioral tracking, no hidden cloud sync. Crash/diagnostic reporting is off until you opt in — one file, privacy.json, is the single source of truth.

Network tuned

Auto-picks the fastest DNS by ping, BBR + larger buffers out of the box, Proton VPN auto-launches after your first profile — never silently.

Adaptive performance

Raw mouse input (no acceleration), tuned keyboard response, and visuals that scale down automatically on weaker hardware so low-end machines stay responsive.

Updates you control

Accept, decline, or defer to midnight / next reboot. If an update fails, Aether self-repairs rather than leaving you on a broken system.

Privacy model

Off until you turn it on

No dark patterns — every toggle in Aether Setup explains exactly what it turns on, and nothing is collected before you say so.

Nothing by default

No telemetry, no advertising identifiers, no behavioral tracking, no hidden cloud sync — out of the box, not behind a toggle you have to find.

One file, one truth

Diagnostics are opt-in only, from Aether Setup → Privacy, and recorded in ~/.config/aether/privacy.json — nowhere else.

You can check it yourself

It's open source: grep -r telemetry /usr/share/aether returns no endpoints. Don't take our word for it.

FAQ

Questions people actually ask

Is AetherOS free?

Yes. Everything here — the OS, the shell, the apps, the website — is open source under the MIT license. Third-party components it installs (Debian, GNOME, Steam, Proton-GE, Zen Browser) keep their own upstream licenses.

Does it run Windows (.exe) or macOS (.dmg/.pkg) apps?

.exe files run through Wine/Aether runtimes. .AppImage and .deb install with a double-click. .dmg/.pkg are macOS binaries and genuinely can't run on Linux — Aether shows a clear prompt and suggests a Linux alternative instead of pretending it can.

How do I verify the ISO before installing?

Every build publishes a checksum alongside it. Download both files, then run sha256sum -c AetherOS-*.iso.sha256 and confirm it says OK before you flash a drive.

What hardware has this actually been tested on?

The build host is a Ryzen 7 5700X; the QEMU matrix covers a 4GB baseline, 2GB weak-hardware (adaptive perf drops blur/transparency), Hi-DPI 4K, and UEFI boot. Physical hardware coverage grows as people boot the USB and report back — see the support matrix.

Why do the apps have separate version tags from the OS?

Aether Browser, Mail, Vault, Updater, and Gaming Hub each change on their own schedule and can be useful without the full ISO. A browser fix shouldn't force a new OS release number — so each component tags and releases independently. See RELEASING.md.
