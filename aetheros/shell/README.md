# Aether Shell

GNOME Shell (Wayland) extensions — original code, no macOS/Windows assets.

- `dock/` — bottom dock with magnification, minimize, drag-to-pin
- `launcher/` — overview search (apps, files, settings), fuzzy
- `topbar/` — status icons (network, audio, power, clock, notifications)
- `notifications/` — center with Do Not Disturb sync

Install:
```bash
gnome-extensions install aether-shell.zip
# or: cp -r shell/* ~/.local/share/gnome-shell/extensions/aether-shell@aether.local/
```
