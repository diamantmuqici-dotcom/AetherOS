Built in, not bolted on

Every Aether component ships with the image. Nothing here needs a post-install download or an account.

PRIVACY

No telemetry, no location tracking

Aether apps collect no usage metrics, advertising identifiers, geolocation, or MAC addresses. Diagnostics are off by default and opt-in only.

INTEGRITY

Ed25519-signed updates

Updates and release metadata are verified against a public key staged inside the image before anything is installed. Invalid or expired signatures stop the update.

AT REST

LUKS2 full-disk encryption

The installer sets up LUKS2 with a keyfile and a 24-word recovery phrase. Your data is encrypted from the first boot.

READY

Preinstalled apps

Browser, mail, vault, antivirus, backup, media tools, and gaming utility are bundled and verified at build time. aether-fix repairs them at runtime.

FAMILIAR

Windows/macOS-style taskbar

Dock, launcher, notifications, workspaces, and window snapping land where you expect them. No relearning the basics.

FOUNDATION

Debian Trixie core

A real Debian base with Aether branding, a custom boot splash, and the Aether-only UI layered on top. No wrapper distro, no proprietary shell.

Three steps to AetherOS

  1. Download and verify

    Grab the amd64 live ISO from the download page, then check its SHA-256 digest and the release signature before you boot. Verification walkthrough.

  2. Flash a USB drive

    Write the image in UEFI mode with your preferred flasher. The image is a hybrid ISO and boots on amd64 hardware.

  3. Boot and set up

    Boot from USB, run Aether Setup, create your vault passphrase and recovery phrase, and you are in.

Verify before booting. A checksum confirms the bytes; the Ed25519 signature confirms the release. Read the verification guide before you write the image to a drive.
