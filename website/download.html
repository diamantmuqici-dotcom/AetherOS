Build and hosting status

The ISO is built in GitHub Actions. No locally built ISO is claimed or hosted here. Links resolve to the project's published Releases assets; if an asset has not been uploaded for the current release, the link returns 404.

After the download

  1. Verify the image

    Check the SHA-256 digest and the signature. Follow the Linux, Windows, and OpenSSL commands.

  2. Flash the ISO

    Write the verified image to a USB drive in UEFI mode, then boot from it.

  3. Set up AetherOS

    Aether Setup creates your vault, passphrase, and recovery phrase. Full-disk encryption is configured during install.
