Privacy commitment · AetherOS 1.0

Nothing leaves the machine by default.

Aether's own components do not phone home. This page lists the exact outbound traffic the OS initiates, the traffic it never initiates, and the boundary around software you install yourself.

What Aether sends

ComponentDestinationWhen
Aether Antivirus Signed definition files from GitHub Releases: aether-av-sigs.json and its .sig, under https://github.com/diamantmuqici-dotcom/AetherOS/releases/latest/download/. Only on an explicit aether-av --update. Definitions are verified in memory before use; a failed fetch or bad signature leaves existing definitions untouched.

That is the complete list of outbound calls initiated by Aether's own software. It is a fetch of two static files over HTTPS from the project's own release channel.

What Aether does not send

NO TELEMETRY

No usage metrics

No analytics, crash uploads, behavior tracking, or advertising identifiers in Aether apps. Diagnostics and crash reporting are off by default and opt-in only.

NO LOCATION

No geolocation

Aether apps do not request or transmit your location, and do not derive it from network or device data.

NO DEVICE IDS

No MAC collection

Aether apps do not collect MAC addresses or hardware serials for tracking or reporting.

NO SYNC

No hidden cloud sync

Vault, mail, and settings stay local. Browser sync and sign-in are disabled by managed policy.

UPDATES

No release-data polling

The updater applies only packages pinned by an already-signed manifest. Its check and plan modes are offline and emit no network request.

CONTROL

One privacy switch

~/.config/aether/privacy.json is the single source of truth for the optional diagnostics toggle. There is no second settings path.

Browser defaults

Aether Browser ships with the search default set to DuckDuckGo. DNS-over-HTTPS is enabled and WebRTC IP handling is hardened so a non-proxied UDP path does not leak your local address. Sync and sign-in are disabled, metrics reporting is off, and notifications are blocked by default.

A bundled content filter blocks known advertising and tracking hosts. These are managed policy and extension settings, not runtime command-line switches.

The third-party boundary

These guarantees cover software Aether ships and configures. Software you install yourself is outside Aether's control: a third-party app can make its own network connections under your user account. That traffic is the app's behavior, not Aether's, and is not covered by this commitment.

Browsing to a site is likewise your own action; the browser's privacy defaults reduce leakage but do not make a remote site private.

Source documents

The full policy text lives in the repository, outside this published site:

  • aetheros/docs/PRIVACY.md — the canonical privacy policy: default-off diagnostics, the privacy.json switch, and the no-cloud-sync rule.
  • aetheros/docs/SUPPORT_MATRIX.md — the per-component status table, including signed updates, browser policy, antivirus, and release metadata.

These are repository-relative paths, not links on this site; the docs are not part of the published website/ directory.
