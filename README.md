# AetherOS — Premium Together OS

**Welcome to Aether.**

Aether is a single OS that feels familiar whether you come from Windows, Linux, or macOS — fully optimized for gaming, built for beginners, and private by design.

### What you get

- **First boot:** Aether Setup — choose wallpaper, appearance, privacy, gaming. No bloat.
- **Desktop:** Dock, taskbar springs, launcher, notifications, workspaces, snap windows.
- **Apps preinstalled:** Files, Terminal, Settings, Task Manager, Notepad, Bin (on desktop), Aether Browser, Aether Mail, Aether Vault, Aether Updater.
- **Gaming:** Steam + Proton-GE, Zen Browser, Game Mode (high priority for your main game), controller support.
- **Speed:** raw mouse (no accel), fast keyboard, adaptive visuals (weak HW stays fast).
- **Privacy:** no serial numbers, no telemetry, 5 layers of encryption on your vault, no data sharing. You choose.
- **Network:** auto-pick fastest DNS by ping, BBR + buffers, Proton VPN auto-launch after first profile.
- **Security:** boot-time lightweight scan (doesn't hurt FPS or ping), manual scan anytime, user can turn it off completely.
- **Files:** `.exe` opens in Aether runtimes, `.AppImage/.deb` double-click install, `.dmg/.pkg` opens with guidance (macOS binaries not run directly).

### Install

1. Download the ISO from Releases (below) or Actions → Artifacts.
2. Flash with Rufus (UEFI, DD mode).
3. Boot USB → follow **Welcome to Aether** → Enter AetherOS.

### Verify

`sha256sum -c *.iso.sha256`
